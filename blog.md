# How I Built My Cybersecurity Portfolio

I started building my cybersecurity portfolio using GitHub Pages because it is free and easy to use. It allowed me to create a personal website without needing to buy a domain.

I created a GitHub repository and added an index.html file, then enabled GitHub Pages in the settings. This turned my repository into a live website that I can update anytime.

This process helped me understand how websites are hosted and how developers use GitHub to manage projects. Even though my portfolio is still basic, it gives me a foundation to build on as I continue learning cybersecurity.

Going forward, I plan to add more projects, improve my GitHub organization, and document my learning journey more consistently.
